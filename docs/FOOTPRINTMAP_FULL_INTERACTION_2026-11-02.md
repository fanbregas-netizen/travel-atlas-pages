## 二、现在可实际操作的完整网页流程

### 1. 发现地点、收藏资料（Footprint Map）

1. 在主地图用既有搜索框查地点，点击地点并加入黄色星标；既有四向 SVG 气泡照旧。
2. 点击主地图左侧「＋ 收藏灵感 / 影像」，或在星标 **Guides** 气泡中点击「＋ 收集社交资料」。
3. 选择已收藏的地点，输入「为什么想去」Brief，粘贴公众号 / 小红书 / Bilibili / YouTube 等的原始 URL 及标题，保存。
4. 保存的数据写入原有浏览器 IndexedDB 数据库，逐项合并，不清空原照片、视频、其他链接；下次打开仍在。四向 Guides 气泡会优先显示实际已保存的链接。

### 2. 规划路线（Travel Atlas 子页）

1. 点击主地图「路线」，进入独立的 Travel Atlas 子页。
2. 选旅行日期、出发地、目的地，从主地图现有星标中挑选地点。
3. 手动排列顺序、分配 D1/D2/D3…、设置各站计划到达时间。也可点击「按地理邻近关系智能分天」，以坐标直线距离的启发式算法生成**可编辑草案**，不宣称这是实际道路最优解。
4. 在右侧（iPhone 下方）显示连续弯曲路径、每一天及每站的独立内容气泡：地点名称、原 Brief、照片预览、社交来源链接、计划到达时间。点击星标返回 Footprint Map；点击高德导航跳转高德地图。
5. 路线保存在**单独的** IndexedDB 数据库，不覆盖主地图收藏。可以新建、保存、恢复、导出/导入 JSON，也可导出详细 Markdown 路书，或复制含地点、Brief、链接的 AI 提示素材。

### 3. 去旅行、影像归档（回流 Footprint Map）

1. 在 Travel Atlas 任一地点气泡点击「＋ 归档影像」，自动回到主地图的影像归档面板并选定该地点。
2. 用户主动从手机选择照片/视频；JPEG 若保留 EXIF GPS，工具尝试在现有星标 2 公里内推荐匹配位置。
3. 每个文件都必须由用户确认目标星标；无 GPS 或视频时可以手动选择对应星标；点击确认后，图片和视频追加到该地点现有媒体库，不覆盖旧媒体。
4. 媒体数据仅留在本浏览器；回到地图可继续查看。建议使用项目原有 ZIP 备份功能保存个人数据。

## 三、必须明确的能力边界

以下功能**还没有真实后端接入，不可对用户冒充已完成**：

- **AI 自动读取微信、小红书、Bilibili、YouTube 完整内容**：当前保存链接和 Brief，能把已有文字、链接整理为 AI 提示素材；跨平台内容抓取需要授权、合法 API/抓取和服务端执行。
- **真正 AI 生成有可靠行车时间、营业时间的行程**：当前是按真实收藏点做位置邻近的自动分天草案与自定义时间表；实际道路时间、景点营业时段需接入可信数据与 AI 服务。
- **iPhone 后台自动读取整本相册并上传**：网页受 iOS 相册与定位权限约束，当前提供用户主动选择 + GPS 定位候选匹配 + 确认归档。无授权不扫描、不同意不上传。
- **339 个高德星标全部已导入**：高德来源缺乏坐标，仍需在导入页面使用服务 Key 解析，并核对再导入；没有拿实际数据或坐标时不得预填伪造点。
- **跨设备云同步**：两部分信息保存在打开网页的那个浏览器中；iPhone Safari 与电脑浏览器不会自动同步。

6. [ ] iPhone Safari 竖屏/横屏测试：按钮不遮挡主地图基本操作；星标泡泡可展开/收起；点击地图空白关闭；页面不冻结。
