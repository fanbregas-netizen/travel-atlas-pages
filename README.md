# Travel Atlas V4

Live site: https://fanbregas-netizen.github.io/travel-atlas-pages/

This repository publishes the static Travel Atlas application. The original development repository remains private.

Search for a destination, save its yellow star, write a Brief, and add photos or videos. Open the star to view four independent SVG cards: Brief, media, guides and nearby attractions. Click the map background to close them.

Photos, videos and notes are saved in this browser's local IndexedDB, not automatically synced between devices. Use the archive's ZIP export/import to back up or transfer everything. Changing website origin does not transfer data: export from the old Vercel site and import on this Pages site.

Map, destination search and nearby attractions use public OpenStreetMap-based services. Availability and geographic coverage depend on these third parties. Location permission is only requested when you press Locate. The static site does not upload your media; shared links contain only the selected location and Brief.
